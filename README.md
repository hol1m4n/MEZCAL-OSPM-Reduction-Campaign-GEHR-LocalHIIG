# MEZCAL-OSPM-Reduction-Campaign-GEHR-LocalHIIG
Campaña de reducción de datos espectroscópicos del MEZCAL-OSPM para GEHR y HIIG locales. 

Los espectros ya reducidos estan en la carpeta Redux. La carpeta Summary contiene el resumen de la campaña de reducción. La carpeta Sigma_fit tiene los ajustes de las lineas usando Gauss y Gauss-Hermite propagando los errores con MonteCarlo. 

La carpeta MEZCAIRAF tiene los scripts y rutinas de IRAF/pyraf que utilicé para realizar la reducción.
