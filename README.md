# MEZCAL-OSPM-Reduction-Campaign-GEHR-LocalHIIG
Campaña de reducción de datos espectroscópicos del MEZCAL-OSPM para GEHR y HIIG locales. 

Las carpetas contienen las imagenes separadas por tipo en formato .png. Los espectros ya reducidos estan en la carpeta OBJS para cada noche. La carpeta Summary de cada noche tiene el resumen de la campaña de reducción. 

La carpeta MEZCAIRAF tiene los scripts y rutinas de IRAF/pyraf que utilicé para realizar la reducción.
